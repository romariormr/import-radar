Política de Privacidade

Import Radar · Última atualização: abril de 2026

Resumo direto: A extensão não coleta, não armazena em servidor e não compartilha dados pessoais. Tudo fica no seu navegador. As únicas chamadas externas são para buscar a cotação do yuan e traduzir títulos de produtos.

1. O que é o Import Radar

O Import Radar é uma extensão gratuita para Chrome que ajuda compradores brasileiros (e de outros países) a navegar no marketplace Goofish (Xianyu / 闲鱼) da Alibaba — o maior marketplace de usados da China — com informações relevantes para quem compra de fora da China:

  • Verifica se smartphones e outros eletrônicos são compatíveis com as redes do seu país (ex: Banda 28 para Brasil, Argentina, etc.)
  • Converte preços de yuan (¥ CNY) para reais (R$ BRL) em tempo real
  • Indica onde comprar via agente de importação (CSSBuy)
  • Indica onde comprar yuan chinês para pagar o produto (Bytemax)
  • Monitora listas de vendedores e alerta quando novos produtos chegam
  • Exibe botão de compra em outros sites de compras chineses (Taobao, Tmall, 1688, Weidian)

2. O que a extensão lê nas páginas

A extensão lê o conteúdo visível das páginas dos seguintes sites para extrair informações de produto:

Site O que é lido Para quê
goofish.com Título, preço, modelo, specs, fotos do produto Filtros, compatibilidade, conversão de preço, alertas
taobao.com / tmall.com URL da página atual Gerar link de compra via CSSBuy (somente ID do produto)
1688.com URL da página atual Gerar link de compra via CSSBuy (somente ID do produto)
weidian.com URL da página atual Gerar link de compra via CSSBuy (somente ID do produto)
✔ Nenhum dado lido das páginas é enviado para servidores externos. O processamento ocorre inteiramente no seu navegador.

3. Chamadas para serviços externos

A extensão faz chamadas para dois serviços externos. Nenhum dado pessoal é enviado:

Serviço URL O que é enviado Para quê
Frankfurter API api.frankfurter.app Nenhum dado pessoal — apenas requisição de cotação CNY→BRL Exibir preços em reais atualizados
Google Translate translate.googleapis.com Título do produto em chinês (quando você clica em "Traduzir") Traduzir títulos de produtos do chinês para português
⚠ Quando você clica em "Traduzir" em um card, o título do produto em chinês é enviado ao Google Translate. Isso é feito pela API pública do Google (sem autenticação). Consulte a Política de Privacidade do Google para entender como eles tratam esses dados.

5. Compatibilidade com redes de celular

A extensão verifica se um smartphone vendido no Goofish é compatível com as redes de telefonia do seu país. Isso é especialmente importante porque muitos celulares vendidos na China possuem versões bloqueadas para redes chinesas e não funcionam corretamente em outros países.

A verificação de compatibilidade:

  • É feita localmente, usando um banco de dados embutido na extensão com modelos de iPhone (A-numbers) e suas bandas de frequência
  • Verifica bandas 4G (LTE) e 5G contra o perfil do país selecionado
  • Para o Brasil: verifica especialmente a Banda 28 (700 MHz), essencial para cobertura Claro, Vivo, TIM e Oi no interior
  • Nenhum dado do seu celular, operadora ou localização é coletado

6. Links de afiliados

A extensão contém links de afiliado para CSSBuy e Bytemax. Quando você clica nesses links e realiza uma compra, o desenvolvedor pode receber uma comissão.

  • CSSBuy — agente de importação que recebe produtos na China e envia para o Brasil. Link de afiliado: cssbuy.com/romariobrito
  • Bytemax — plataforma para compra de yuan chinês (CNY) via PIX. Link de afiliado: bytemax.exchange?ref=D252BD1D

Os links de afiliado são gerados localmente no seu navegador a partir do ID do produto na URL. Nenhum servidor intermediário é usado. Você não é rastreado pelo desenvolvedor da extensão.

7. Monitoramento de sites de compras

A extensão também funciona nas seguintes plataformas de compras chinesas para exibir um botão de compra rápida via CSSBuy:

  • Taobao (taobao.com) — maior marketplace da China
  • Tmall (tmall.com) — marketplace de marcas oficiais
  • 1688 (1688.com) — marketplace atacadista B2B
  • Weidian (weidian.com) — loja independente chinesa

Nesses sites, a extensão lê apenas a URL da página atual para extrair o ID do produto e gerar o link de compra. Nenhum conteúdo adicional da página é lido ou enviado.

Todo HTML gerado dinamicamente pela extensão é sanitizado com uma função de escape antes de ser inserido na página, prevenindo ataques de injeção de código (XSS). A extensão não usa eval() nem executa código JavaScript externo.

Esta extensão não é destinada a pessoas com menos de 13 anos e não coleta dados de crianças intencionalmente.

Privacy Policy

Import Radar · Last updated: April 2026

Quick summary: This extension does not collect, store on servers, or share personal data. Everything stays in your browser. The only external calls are to fetch the yuan exchange rate and to translate product titles.

1. What is Import Radar

Import Radar is a free Chrome extension that helps buyers outside China navigate the Goofish (Xianyu / 闲鱼) marketplace from Alibaba — China's largest second-hand marketplace — with relevant information for international buyers:

  • Checks if smartphones and electronics are compatible with your country's mobile networks (e.g. Band 28 for Brazil, Argentina, etc.)
  • Converts prices from yuan (¥ CNY) to your local currency in real time
  • Shows where to buy via a shipping agent (CSSBuy)
  • Shows where to buy Chinese yuan to pay for the product (Bytemax)
  • Monitors seller lists and alerts when new matching products appear
  • Shows a buy button on other Chinese shopping platforms (Taobao, Tmall, 1688, Weidian)

The extension reads the visible content of the following websites to extract product information:

✔ No data read from pages is sent to external servers. All processing happens entirely in your browser.

5. Mobile network compatibility

The extension checks whether a smartphone sold on Goofish is compatible with the mobile networks of your country. This matters because many phones sold in China are carrier-locked or lack the frequency bands used in other countries.

  • Compatibility check is done locally, using a database embedded in the extension (iPhone A-numbers and their frequency bands)
  • Verifies 4G (LTE) and 5G bands against the selected country profile
  • For Brazil: specifically checks Band 28 (700 MHz), critical for Claro, Vivo, TIM and Oi rural coverage
  • No data about your phone, carrier, or location is collected
